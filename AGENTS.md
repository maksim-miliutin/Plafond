# Правила кода Plafond

Код, комментарии, имена и сообщения коммитов по-английски.

## Тире

Длинное тире (U+2014) и среднее (U+2013) запрещены везде: код, строки, комментарии, тесты, тексты интерфейса, письмо, коммиты, документы. Вместо них точка, запятая, двоеточие или скобки; в диапазонах дефис. Проверка стоит первой в списке ниже и в CI.

## Код

Открывающая скобка с новой строки у каждого блока: функции, методы, классы, if, for, while, switch, try. Отступ четыре пробела.

Ранний выход: условие-отказ наверх, else после return не пишется. Три уровня отступа: сигнал выйти раньше.

Пустая строка там, где меняется мысль; связанные строки вплотную.

Имена длиной в область видимости. Общепринятые (id, db, url, api, ms, err, row, i, s, v) не разворачивать; сокращения на один проект (resp, cfg, btn, idx) разворачивать; tmp и data запрещены.

Больше трёх параметров: один объект со своим типом и именованными полями.

Функция возвращает результат, а не меняет переданное. Зависимости (дату, часы, сеть, базу, таблицу ставок) принимает параметром, а не достаёт внутри.

Один факт в одном месте: таблица, из которой берётся всё, и тест, который ходит по самой таблице.

## Ошибки

Ожидаемый отказ (адрес не распознан, город вне зоны, нет ставки на дату) возвращается значением с полем kind, а не бросается. Бросается только поломка: экспортированный класс ошибки, проверка через instanceof, текст начинается с имени модуля ("cap: ..."). Чужую ошибку заворачивать через cause, а не подменять.

## Комментарии

По умолчанию их нет; три-пять процентов строк. Оправданы в четырёх случаях: чужое правило (закон, постановление, формат опубликованной таблицы, повадки BAN), ловушка с молчаливой поломкой, отказ от очевидного, единица измерения или значение нуля, если их не видно из типа. Не больше одного на функцию, не длиннее двух строк. JSDoc над экспортами внутренних пакетов не писать. Комментировать намерение, а не поведение.

## Тесты

Сначала тест, потом код. Имя теста говорит, что обещано, а не что вызывается. Проверять через открытые функции модуля. Сломать проверяемое место одной правкой и убедиться, что тест краснеет; ошибка сборки тоже поимка. Тесты не трогают ни сеть, ни диск, ни базу. Над тестом на уже случившуюся ошибку комментарий, от чего он сторожит. Ожидаемые суммы берутся из официального расчётчика или независимого счёта, а не из прогона нашего кода.

## Plafond

Ни одной ставки в коде: ставка это строка данных с датой начала, датой конца и ссылкой на постановление. Расчёт всегда на явно переданную дату; текущую дату домен не читает. Деньги в целых центах, правило округления одно и в одном месте. packages/domain не импортирует ни Next, ни React, ни React Native, ни драйвер базы. Адрес и сумма аренды не сохраняются на сервере и не пишутся в логи. Ни интерфейс, ни письмо не называют complément de loyer незаконным.

## Коммиты и репозиторий

Коммиты строчными, по-английски, без точки, два-четыре слова, без префиксов. Один коммит, одно дело. В репозитории только то, что нужно для сборки и запуска, плюс README и этот файл. Не коммитятся сборки, .env, ключи, токены, логи.
